# מאפה גן עדן - אתר

אתר סטטי (HTML/CSS/JS) למאפייה ובית הקפה מאפה גן עדן, מבוא האתרוג 7, אשדוד.

## העלאה ל-GitHub Pages
1. יוצרים מאגר חדש ב-GitHub (שם קצר באנגלית, למשל `maafe-gan-eden`).
2. נכנסים לתיקייה, `Ctrl+A` על כל הקבצים (לא על התיקייה עצמה) וגוררים לחלון ההעלאה.
3. בהגדרות המאגר: Pages ← Branch: main ← Save.
4. הכתובת: `https://<user>.github.io/<repo>/` (עם / בסוף).

## אם משהו לא עובד
- לוודא שהקבצים נמצאים בשורש המאגר ולא בתוך תיקייה נוספת.
- לוודא שהקבצים המוסתרים (`.nojekyll`) הועלו.
- לבדוק שהכתובת מסתיימת ב-`/`.
